# Barbearia Novo Visual

Site institucional desenvolvido para a **Barbearia Novo Visual**, com o objetivo de apresentar os serviços, profissionais e informações de contato do estabelecimento.

## Funcionalidades

- Apresentação da barbearia e de sua história.
- Exibição dos serviços e respectivos preços.
- Apresentação dos profissionais.
- Informações de contato e horário de funcionamento.
- Botão para agendamento via WhatsApp.
- Layout responsivo, adaptado para computadores e dispositivos móveis.
- Ano de copyright atualizado automaticamente com JavaScript.

## Tecnologias utilizadas

- **HTML5:** estrutura e organização do conteúdo.
- **CSS3:** estilização, cores, espaçamentos e responsividade.
- **Bootstrap 5:** componentes e menu de navegação responsivo.
- **JavaScript:** atualização automática do ano no rodapé.

## Estrutura do projeto

- `index.html` – estrutura da página.
- `style.css` – estilos visuais.
- `script.js` – funcionalidades JavaScript.
- Arquivos de imagem – fotos utilizadas no site.
